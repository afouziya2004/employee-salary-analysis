# Employee Salary Analysis & Insights

A data analytics project that analyzes employee salary data
to extract insights using Python and Pandas.

## Objectives
- Analyze salary distribution
- Compare salaries across departments
- Identify high & low performers
- Visualize salary trends

## Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib

## Project Structure
- data/ : dataset
- src/ : analysis script
- notebooks/ : exploratory analysis
- visuals/ : generated plots

## How to Run
pip install -r requirements.txt  
python src/employee_analysis.py
